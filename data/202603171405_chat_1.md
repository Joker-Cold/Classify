- `IMPSYUTIL-96`: placement 格式变化

**解决方案**：改用版本无关的标准格式（DEF/Verilog/LEF/LIB）通过 `init_design` + `defIn` 加载设计。

```tcl

    ../../db/des3.enc.dat/libs/lef/asap7_tech_4x_201209.lef \
    ../../db/des3.enc.dat/libs/lef/asap7sc7p5t_28_L_4x_220121a.lef \

The supported version numbers for this file are 3 through 8.
```

### 🤖 Claude

**Power Grid Library (`techonly.cl`) 是 v19 生成的**（格式版本 12），v15 只支持版本 3-8。

解决方案：去掉 `-power_grid_library` 参数，先 `set_power_analysis_mode -reset`，再不指定 `.cl` 文件重新执行：

```tcl
set_power_analysis_mode -reset
set_power_analysis_mode \
    -method dynamic_vectorbased \
    -create_binary_db true \
    -current_generation_method avg
read_activity_file -format VCD ../../vcd/test.vcd -scope test/u0 -start 4000ns -end 5000ns
set_dynamic_power_simulation -resolution 1ns
report_power -o ../../db/power/avg_v15
```
