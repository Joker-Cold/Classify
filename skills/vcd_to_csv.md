# Skill: Convert VCD to CSV

## Goal

Convert a VCD waveform file into CSV format for data analysis.

The CSV output can be used for:
- Python data processing
- machine learning
- toggle analysis
- power estimation

---

## When to Use

Use this skill when:
- preparing waveform data for Python (task1)
- running statistical analysis on signal toggles
- building ML datasets from simulation results

Example:
```
vcd_to_csv simulation.vcd output.csv
```

---

## Input

Required:
- VCD file path

Optional:
- signal list (subset of signals)
- time range
- output CSV file path

Example:
```
VCD: sim.vcd
Signals: clk data valid
Output: waveform.csv
```

---

## Workflow

1. Parse VCD header
2. Extract signal definitions → build symbol mapping
3. Parse value changes section
4. Build time-aligned dataset (hold-last-value semantics)
5. Export per-signal CSV files + optional combined CSV
6. Write `signal_manifest.json` (signal name, type, width, symbol, csv_file)

---

## Symbol Table Example

```
$var wire 1 ! clk $end
$var wire 8 " data[7:0] $end

Mapping:
  clk  →  !
  data →  "
```

---

## Output Formats

### Per-Signal CSV (CSV1)
One file per signal, sparse (only time points where the signal changes):
```
time,value
0,0
10,1
20,0
```

### Combined CSV
All signals in one file, one row per time point where any signal changes:
```
time,clk,data,valid
0,0,0,0
10,1,4,0
20,0,7,1
```

> **Note**: Combined CSV uses hold-last-value semantics — each row shows the current value of every signal, not just the one that changed.

### signal_manifest.json
```json
{
  "vcd_source": "sim.vcd",
  "timescale": "1 ns",
  "scope": "tb_top",
  "signals": [
    {"name": "clk",  "type": "wire",    "width": 1,  "symbol": "!", "csv_file": "clk.csv"},
    {"name": "data", "type": "wire",    "width": 8,  "symbol": "\"", "csv_file": "data.csv"}
  ]
}
```

---

## Common Issues

| Problem | Cause | Solution |
|---------|-------|---------|
| Signal not in CSV | symbol not in `$var` | Check VCD header parsing |
| Combined CSV missing values | iterator copy bug | Use index pointer, not `copy.copy(iter)` |
| Wrong signal name mapping | hardcoded name map | Use `signal_manifest.json` generated by task1 |
