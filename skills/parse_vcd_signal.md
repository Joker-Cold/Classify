# Skill: Parse VCD Signal Waveform

## Goal

Extract the full waveform of a specific signal from a VCD (Value Change Dump) file generated by Verilog simulations.

The output should contain the time-value sequence for the selected signal.

This skill is useful for:

- Debugging signal transitions
- Waveform analysis
- Generating datasets for Python scripts
- Automated verification pipelines

---

## When to Use

Use this skill when:

- You need the waveform of a single signal from a large VCD
- You want to analyze signal transitions using Python
- You want to inspect signal toggling during simulation

Example request:


parse_vcd_signal sim.vcd clk


---

## Input

Required:

- VCD file path
- signal name

Example:


VCD file: simulation.vcd
Signal: data_valid


Optional:

- time range

---

## Workflow

1. Open the VCD file
2. Parse header definitions
3. Locate `$var` declarations
4. Map signal name to symbol
5. Read value change section
6. Extract all time-value pairs for the symbol
7. Produce ordered waveform data

---

## Key VCD Elements

### Variable Definition


$var wire 1 ! clk $end


Fields:

| Field | Meaning     |
| ----- | ----------- |
| wire  | type        |
| 1     | width       |
| !     | symbol      |
| clk   | signal name |

---

### Time Change


#10


Simulation time = 10

---

### Value Change

Scalar example:


1!
0!


Vector example:


b1010 "


---

## Extraction Algorithm

1. Build a symbol table

Example:


clk -> !
data -> "
valid -> #


2. Locate target symbol


symbol = table[signal_name]


3. Parse time/value changes

Pseudo logic:


current_time = 0

for line in file:
if line starts with '#':
current_time = parse_time(line)

if line matches value change:
    if symbol matches target:
        record(current_time, value)

## Optional Filters

### Time Range


start_time = 0
end_time = 1000


Only extract within range.

---

### Toggle Count

Return number of transitions.

Example:


Total transitions: 120


---

## Common Issues

| Problem                | Cause                |
| ---------------------- | -------------------- |
| Signal not found       | missing `$var`       |
| Empty waveform         | signal never toggled |
| Duplicate signal names | hierarchical scope   |
