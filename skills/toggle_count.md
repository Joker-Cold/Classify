# Skill: Count Signal Toggles per Clock-Cycle Window

## Goal

Count the total number of signal value changes (toggles) within each N-clock-cycle window,
producing a per-window toggle statistics file used for worst-case identification.

This skill underpins task2 of the VCD compression pipeline.

---

## When to Use

Use this skill when:
- Computing per-window activity metrics from signal CSV files (task2)
- Determining which time windows are most active
- Providing input data for `worst_case_identification.md`

---

## Input

Required:
- `signal_manifest.json` — maps signal names to their CSV file paths and metadata
- Per-signal CSV files (generated by task1 / `vcd_to_csv.md`)
- Window size N (number of clock cycles per window, e.g. 5 or 10)

Optional:
- Clock signal name (default: `clk`)
- Multiple window sizes (e.g. `[5, 10]`)

---

## Key Definitions

**Toggle**: Any value change for a signal within a time range.
- Scalar: `0→1`, `1→0`, `x→0`, etc.
- Vector: any change in binary string value

**Clock window**: A contiguous span of N clock cycles, defined by clock rising edges.

**Excluded signals**: The clock signal (`clk`) is NOT counted in toggle statistics — it is used only as the time reference.

---

## Algorithm

### Step 1: Extract Clock Rising Edges
```python
# From clk.csv, find all times where clk transitions 0→1
rising_edges = []
prev = None
for time, value in clk_waveform:
    if prev == '0' and value == '1':
        rising_edges.append(time)
    prev = value
```

### Step 2: Define Windows
```python
windows = []
for i in range(0, len(rising_edges) - N, 1):  # non-overlapping start
    window_start = rising_edges[i]
    window_end   = rising_edges[i + N]
    windows.append((i+1, window_start, window_end))
```

### Step 3: Preload All Signal Waveforms
```python
# Load once, reuse for all windows — avoid per-window file reads
waveforms = {}
for sig in manifest['signals']:
    if sig['name'] != clock_signal:
        waveforms[sig['name']] = read_csv(sig['csv_file'])
```

### Step 4: Count Toggles per Window
```python
def count_toggles_in_window(waveform, window_start, window_end):
    # Find the last value before window_start as baseline
    prev_value = None
    for time, value in waveform:
        if time < window_start:
            prev_value = value
        elif time >= window_start:
            break

    # Count changes within [window_start, window_end)
    count = 0
    for time, value in waveform:
        if time < window_start:
            continue
        if time >= window_end:
            break
        if value != prev_value:
            count += 1
        prev_value = value
    return count
```

### Step 5: Aggregate and Write CSV2
```python
for window_idx, window_start, window_end in windows:
    total = sum(count_toggles_in_window(waveforms[s], window_start, window_end)
                for s in waveforms)
    write_row(window_idx, window_start, window_end, total)
```

---

## Output Format (CSV2)

```csv
window_index,window_start_time,window_end_time,toggle_count
1,10,110,3
2,30,130,9
3,50,150,9
4,70,170,8
...
```

| Column | Meaning |
|--------|---------|
| `window_index` | 1-based window number |
| `window_start_time` | simulation time of first clock edge in window |
| `window_end_time` | simulation time of last clock edge in window |
| `toggle_count` | total toggle count across all non-clock signals |

---

## Performance Notes

- **Preload all waveforms** before the window loop — do NOT read CSV files inside the per-window loop (causes O(windows × signals) file I/O)
- Use a **single-pass pointer** per signal rather than iterating from the start for each window
- For large VCDs, consider building a `{time: value}` dictionary per signal for O(1) lookup

## Common Issues

| Problem | Cause | Solution |
|---------|-------|---------|
| 0 toggles everywhere | clock CSV used as data signal | Exclude `clk` from toggle counting |
| Toggle count too high | Window overlaps adjacent window | Check rising edge indexing |
| Missing windows | Fewer than N rising edges | Reduce N or use longer simulation |
| Hardcoded signal names | Old `find_all_signal_csvs()` logic | Use `signal_manifest.json` instead |
