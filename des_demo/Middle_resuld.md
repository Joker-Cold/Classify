## 四、覆盖率评估结果

> 覆盖率方法论详见 `docs/coverage_methodology.md`，本节展示实际计算结果。

### 4.1 三级覆盖率指标体系

本项目采用三级渐进式覆盖率框架，以全集 VCD 仿真结果 Φ(S_full) 为 Ground Truth：

```
 ┌──────────────────────────────────────────────────────────┐
 │  Tier-1: 全局指标 (已实现，基于 Voltus 文本报告)          │
 │                                                          │
 │  C₁ = ΔV(sub)/ΔV(full)         全局最坏 IR Drop 捕获率   │
 │  C_peak = Ipeak(sub)/Ipeak(full) 峰值电流捕获率           │
 │  C_layer(l) = ΔV_l(sub)/ΔV_l(full) 逐金属层 IR Drop     │
 │  C_violation                     违规一致性               │
 │                                                          │
 │  判据: C₁ ≥ 95%, C_layer_min ≥ 80%                      │
 ├──────────────────────────────────────────────────────────┤
 │  Tier-2: 空间指标 (待实现，需 instance-level 电压导出)     │
 │                                                          │
 │  C₂ = Hotspot Recall/F1        危险区域检出率             │
 │  判据: C₂ ≥ 90% (θ = 7% × Vnom)                        │
 ├──────────────────────────────────────────────────────────┤
 │  Tier-3: 统计指标 (待实现)                                │
 │                                                          │
 │  C₃ = Q_99%(ΔV_sub)/Q_99%(ΔV_full)  分位数捕获率        │
 │  判据: C₃ ≥ 90%                                         │
 └──────────────────────────────────────────────────────────┘
```

### 4.2 Tier-1 指标定义与数据来源

| 指标 | 公式 | 数据来源 | 状态 |
|------|------|---------|------|
| **C₁** | (V_nom − V_min_sub) / (V_nom − V_min_full) | `VDD.main.rpt` | ✅ 已计算 |
| **C_peak** | I_peak_sub / I_peak_full | `VDD.main.rpt` / `VDD_dynpwr.rpt` | ⚠️ v20 数据不可用 |
| **C_layer(l)** | ΔV_l(sub) / ΔV_l(full), l ∈ {M1..M6, LISD} | `VDD.layerbased_ir.rpt` | ✅ 已计算 |
| **C_layer_avg** | MEAN(C_layer(l)) | 派生 | ✅ |
| **C_layer_min** | MIN(C_layer(l)) | 派生 | ✅ |
| **C_violation** | 全集/子集违规状态一致性 | `VDD.main.rpt` Violations 字段 | ✅ |

> **C_peak 说明**：v20 algo_grid 仿真报告中 `Peak Dynamic Current Loaded = 0.000A`，Voltus 未输出有效峰值电流数据，该指标标记为 N/A。等分窗口同样缺失。后续可通过 `dynpwr.rpt` 补充。

### 4.6 关于 C > 100% 的物理解释

algo_win1/2 和 eq_win2 的部分金属层 C_layer 超过 100%（最高 LISD 106.5%），即子集 IR Drop > 全集。

**原因**：子集 VCD 切片从 t=0 重新开始仿真，与全集在同一时段的仿真存在**初始条件偏差**：

```
全集仿真:  ───[前段活动]───[目标窗口]───[后段活动]───
                            ↑ 退耦电容已被前段活动部分耗尽

子集仿真:  [目标窗口从 t=0 开始]
            ↑ 退耦电容从满充状态开始
              → 前段 IR Drop 偏低，但高活跃段充分耗尽后反而略超全集
```

这不影响覆盖率评估的有效性——C_layer > 100% 意味着子集的"悲观度"不低于全集，从 sign-off 角度是**保守且安全**的。

### 4.7 覆盖率结论

1. **算法选窗 (algo_win1 + algo_win2) 仅占全 VCD 的 9.3%，Tier-1 全部指标达到 100% 覆盖**。
2. 等分方案中，单独的 eq_win2 (20%) 也能达到 C₁ = 100%，但需要 2 倍以上的 VCD 时长。
3. 等分最差窗口 eq_win3 (C₁ = 84.6%, C_layer_min = 79.9%) 判定为 FAIL。
4. 所有场景 0 violations (阈值 0.651V)，C_violation 无区分力——电源网格裕量充足，当前设计不存在 violation 边界情况。
5. **待补充**：C_peak (需重跑 Voltus 并启用 peak current 输出)、Tier-2 Hotspot C₂、Tier-3 分位数 C₃。

## 五、关键发现

### 5.1 Worst-case 时间定位

- full 仿真的 Worst Case Interval = **4.050us**，对应绝对时间落在 eq_win2 (2370~4740ns) 范围内
- algo_win1 (3790~4390ns) 精确覆盖了该 worst-case 时刻
- Phase-Aware 算法的 depletion_ratio=0.7 定位策略有效

### 5.2 窗口间差异

| 排名 | 窗口 | Max IR Drop | 与 full 的差距 |
|------|------|-------------|---------------|
| 1 (worst) | eq_win2 / algo_win1 / algo_win2 | 26mV | 0mV (完全匹配) |
| 2 | eq_win4, eq_win5 | 25mV | −1mV |
| 3 | eq_win1 | 24mV | −2mV |
| 4 (best) | eq_win3 | 22mV | −4mV |

窗口间 IR Drop 差异范围：22mV ~ 26mV，相对差异 18%。

### 5.3 Layer 分布特征

- **上层金属 (M5/M6)**：IR Drop 主要受电源入口分布影响，在 worst 窗口达 23.2mV
- **下层金属 (M1/M2)**：IR Drop 受局部单元电流密度影响，algo_win 中超过 full 基线 (M1: 23.1 vs 21.6mV, +6.9%)
- **LISD 层**：IR Drop 全局最大 (algo_win 达 24.7mV, 超 full 的 23.2mV 达 +6.5%)，为标准单元直连的本地互连层

### 5.4 压缩效率对比

| 方案 | 窗口数 | VCD 时长占比 | C₁ | C_layer_min | Tier-1 判定 |
|------|--------|-------------|------|-------------|-----------|
| 算法选窗 | 2 | **9.3%** | 100% | 100% | CONDITIONAL PASS |
| 等分最优单窗 (win2) | 1 | 20% | 100% | 100% | CONDITIONAL PASS |
| 等分两窗 (win2+win4) | 2 | 40% | 100% | 100% | CONDITIONAL PASS |
| 全部等分 | 5 | 100% | 100% | 100% | CONDITIONAL PASS |

> 算法选窗在 **不到 1/10 的仿真时长** 内达到了与全集相同的覆盖率，验证了 Phase-Aware + 空间集中度选窗方法的有效性。
